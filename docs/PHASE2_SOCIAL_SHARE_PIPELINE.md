# Phase 2 — Social + Share Pipeline

## HSV Civic Watch

HSV social uses published issue cards only. Evidence of Change / bright stories do not post to social.

Rotation pattern:

```txt
Module 1 issue card 1
Module 2 issue card 1
Module 3 issue card 1
...
Module 1 issue card 2
Module 2 issue card 2
Module 3 issue card 2
...
```

Social generation is code-template based by default. No automatic Claude call.

## Veritas Chronicle

Every 3 days, prepare one post from every active category:

```txt
scandal_front_page
receipts_flip
shame_patriot
caught_on_camera
weird_file
useful_fact
pattern_engine
revolving_door
quote_vs_record
```

A/B preview applies to Veritas API suggestions only. Default Instagram/social stamp: `READ THE RECEIPTS`.

## Hashtag Scout

Hashtag Scout is on-demand only, right before posting. It is not scheduled and not automatic.

HSV scope includes Huntsville, HSV, Madison County, Tennessee Valley, North Alabama, Redstone Arsenal, Southeast, Alabama civic topics, worker rights, annexation, zoning, development, voting rights, polling places, utilities, and schools.

Veritas scope includes national scandal topic, named official/person/company, agency/policy/topic, current media cycle, and relevant viral hashtags only.

## Public sharing

HSV share previews should include title, 2–3 sentence useful summary, direct issue-card link, and issue image/stat image if available.

Veritas share previews should include absurd headline, absurdity score, short teaser, image/GIF/cartoon thumbnail, and direct item link.

Manual posting remains required.
